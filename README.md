# The Quokka Company Support Site

GitHub Pages source for support, marketing, and privacy pages shared by The Quokka Company apps.

## Published routes

- `/linkerlinker/`
- `/linkerlinker/support/`
- `/linkerlinker/privacy/`

## GitHub Pages

Publish from the `main` branch at the repository root. After publishing, connect `support.thequokkacompany.com` in GitHub Pages and add the DNS record at the domain provider.
